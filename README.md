## 🎮 About

ProjectBINGO is a dynamic web application that brings the classic game of BINGO to the digital world. Built with clean HTML architecture, this project demonstrates modern web development practices while delivering an engaging user experience.

### Why ProjectBINGO?
- 🎯 **Interactive Gameplay** - Engaging BINGO experience in your browser
- 🌐 **Web-First Design** - No downloads required, play anywhere
- 🎨 **Clean Interface** - Intuitive and user-friendly design
- 📱 **Responsive Layout** - Works seamlessly across all devices

## ✨ Features

- 🎲 **Random Number Generation** - Fair and unpredictable game mechanics
- 🏆 **Win Detection** - Automatic pattern recognition and victory announcements
- 🎨 **Customizable Cards** - Generate unique BINGO cards for each player
- 📊 **Game Statistics** - Track your wins and playing history
- 🔄 **Reset Functionality** - Start new games with ease
- 💾 **Local Storage** - Save game progress and preferences

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- Basic understanding of HTML/CSS/JavaScript (for development)

### Quick Start
1. Clone the repository
2. Open `index.html` in your web browser
3. Start playing BINGO!

## 🔧 Installation

### For Players
```bash
# Clone the repository
git clone https://github.com/thewriterben/ProjectBINGO.git

# Navigate to the project directory
cd ProjectBINGO

# Open in your browser
open index.html
# or
start index.html  # Windows
# or
xdg-open index.html  # Linux
```

### For Developers
```bash
# Clone and setup for development
git clone https://github.com/thewriterben/ProjectBINGO.git
cd ProjectBINGO

# If using a local server (recommended for development)
python -m http.server 8000
# or
npx serve .
```

## 🎯 Usage

### Basic Gameplay
1. **Start a New Game** - Click "New Game" to generate your BINGO card
2. **Mark Numbers** - Click on called numbers to mark your card
3. **Win Conditions** - Complete a line (horizontal, vertical, or diagonal) to win
4. **Reset** - Start over with a fresh card anytime

### Advanced Features
- **Multiple Cards** - Play with multiple BINGO cards simultaneously
- **Custom Patterns** - Try different winning patterns beyond traditional lines
- **Speed Settings** - Adjust the pace of number calling

## 🎮 Game Rules

### Traditional BINGO
- Each card contains 25 squares (5x5 grid)
- Center square is typically "FREE"
- Numbers are called randomly
- First to complete a pattern wins

### Supported Patterns
- **Line BINGO**: Complete any row, column, or diagonal
- **Full House**: Mark all numbers on your card
- **Four Corners**: Mark all corner squares
- **Custom Patterns**: Define your own winning conditions
